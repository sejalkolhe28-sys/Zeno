# 🤖 Zeno AI

Zeno AI is a modern AI chatbot built using Flask and Google's Gemini API.

It features a clean glassmorphism UI, multiple beautiful themes, speech recognition, chat history, file uploads, and a responsive design inspired by modern AI assistants.

---

## Features

- Modern Chat Interface
- Multiple Themes
  - Midnight
  - Ocean
  - Elysium
  - Nebula
  - Sakura
  - Light
- Speech Recognition
- File Upload Support
- Chat History
- Responsive Design
- Flask Backend
- Gemini AI Integration

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Zeno.git
```

Go inside the project

```bash
cd Zeno
```

Create virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
